# Архивные редиректы — 03.10.2026

Проверены 971 существующее правило 301 и архивные ссылки основного сайта.
Сопоставление WordPress ID использует RSS GUID, `rel=shortlink` и HTML
`id=post-ID` вместе с постоянным адресом записи. Цели взяты из существующих
редиректов, `source_url` опубликованных страниц и подтверждённых замен разделов.

Источники:

- https://web.archive.org/web/20240530221245/https://www.x-intellect.org/feed/
- https://web.archive.org/web/20240422115059/https://www.x-intellect.org/contacts/
- Архивная `/map/`, помесячные архивы, внутренние ссылки и ранее сохранённые
  HTML-снимки в `storage/app/wayback-posts/`.

Указанная RSS-лента содержит только 10 последних записей. Архивная карта
сайта сохранилась с нераскрытыми шорткодами. Поэтому дополнительно разобраны
архивные списки и сами страницы. В ходе обхода скачаны 96 HTML-страниц из 210
проверенных адресов; для остальных архив вернул ошибки соединения или 404.
Дополнительно разобраны 67 ранее сохранённых HTML-снимков.

Найдено 123 WordPress ID: 105 сопоставлены с действующими страницами/разделами,
18 не имеют подтверждённой замены. Проверены 533 различных внутренних адреса.

## Добавления

[`legacy-redirects-2026-10-03.json`](legacy-redirects-2026-10-03.json) содержит
127 новых правил: 105 `/?p=ID` и 22 старых адреса курсов, рубрик, форума,
истории проекта, карты сайта и проекта «Душа».

Для частей 1–3 «Души» сопоставлены также первые реплики стенограмм: тексты
сохранились в вики. `/history` соответствует обновлённой истории проекта.
Старые рубрики проектов ведут в соответствующие подразделы. `/map` и ID 1960
ведут к действующей XML-карте `/sitemap.xml`. Старые разделы форума ведут в
индекс архива, а ссылки на сообщения/темы — к теме с тем же phpBB ID.

WordPress ссылки `/?p=ID`, `/index.php?p=ID`, `/?page_id=ID` и варианты с
дополнительными параметрами обслуживаются одной записью `/?p=ID`.
Точное правило для полного URL имеет приоритет. На других путях параметр
`p` не перехватывается; POST и некорректные ID не перенаправляются.

Для ID 1 (приветствие) и 259 (правила) выбраны сами перенесённые тексты,
поскольку прежние корневые адреса сейчас являются листингами разделов.

- Все 113 уникальных целей новых правил отдают HTTP 200 до применения.
- Новые `from_path` уникальны и не пересекаются с существующими правилами.

- 335 тестов / 1013 проверок прошли, включая варианты WordPress ссылок,
  точный приоритет и защиту от перехвата других маршрутов.
- После применения все 127 новых правил и 4 дополнительных варианта
  WordPress ссылок проверены по HTTP: 131 из 131 дают ожидаемый 301.
- На проде теперь 1098 правил 301 (1101 запись вместе с тремя 302).
- Аудит `redirects:check` распознаёт действующую публичную XML-карту сайта,
  не помечая её ошибочно как отсутствующую страницу.
